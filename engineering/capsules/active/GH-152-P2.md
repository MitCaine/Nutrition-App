# GH-152-P2 — Restore frozen 0003 performance-fixture nutrient authority

## Goal

Restore the Phase 5C performance fixture's original frozen-schema nutrient
authority so fixture generation at migration `0003_usda_source_identity`
remains valid after later runtime nutrient-catalog expansion.

## Outcome

The performance fixture recognizes and generates only the 16 nutrient
identities available at its intentionally frozen 0003 source revision.

Current runtime nutrient-catalog growth no longer changes historical fixture
source admission, profile dimensions, generated nutrient rows, Daily Log
snapshot nutrient identity, or deterministic generator-v1 semantics.

The two currently failing PostgreSQL performance-fixture tests reach their
intended assertions.

## Non-goals

- Changing the current 43-nutrient runtime catalog.
- Reverting migrations 0029 or 0030.
- Adding historical nutrients to the frozen source schema.
- Advancing the performance fixture's source revision beyond 0003.
- Changing Phase 5C conversion behavior.
- Changing fixture-generator or performance-manifest contract versions.
- Repairing the separate frozen-0019 metadata-comparison failure.
- Changing performance budgets.
- Requiring full T0-T3 benchmark runs for this compatibility correction.

## Background

The performance fixture is explicitly tied to
`0003_usda_source_identity`.

Migration 0001 owns the historical nutrient seed and contains exactly 16
nutrient identities. Its source explicitly states that historical seed data
must not import the live runtime catalog.

The current runtime catalog contains 43 identities after later migrations.

The fixture nevertheless imports `NUTRIENT_CATALOG` and currently uses that
live authority for:

- clean-source catalog admission;
- public T0-T3 `nutrients_per_food`;
- generated Food nutrient rows;
- Daily Log snapshot nutrient identity.

This makes a frozen historical fixture change whenever the current runtime
catalog grows.

Current main reproduces exactly two PostgreSQL failures rooted at:

`Performance fixture nutrient catalog is unsupported`

Changing only the admission equality check would be incomplete because public
fixture dimensions and generated rows would still request post-0003 nutrient
identities.
