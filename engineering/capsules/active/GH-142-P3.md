# GH-142-P3 — Extract reusable Daily Log test builders

## Goal

Remove the remaining generic Daily Log test-to-test builder authority by moving
stable Daily Log setup helpers into an explicit domain-specific
`tests.support.daily_logs` module.

## Outcome

When P3 is complete:

- `post_log`, `stored_log`, and `create_serving_log` live in
  `apps/backend/tests/support/daily_logs.py`;
- private `_default_serving` lives there only as the implementation dependency
  of `create_serving_log`;
- `test_recipe_revision_logging.py` no longer defines `_post_log` or
  `_stored_log`;
- `test_recipe_revision_log_editing.py` no longer defines `_default_serving`
  or `_create_serving_log`;
- the six audited cross-test statements for those helpers are redirected to
  `tests.support.daily_logs`;
- the repository cross-test graph falls from exactly 23 statements to exactly
  17;
- helper behavior is unchanged;
- collection remains exactly 2262 tests;
- affected tests and full backend baseline remain green;
- production code and database semantics remain unchanged.

## Non-goals

- Moving `_projection_state` from `test_recipe_dependency_deletion.py`.
- Moving capture-specific `_published_recipe`.
- Extracting USDA helpers.
- Refactoring Phase 5/control/PostgreSQL fixture authorities.
- Extracting Target, OCR, or other low-fan-out Epic-specific helpers.
- Changing Recipe support established by GH-142-P2R1.
- Changing Food support established by GH-142-P1.
- Moving helpers into `conftest.py`.
- Creating a generic catch-all test helper module.
- Changing Daily Log product behavior, persistence, history, ownership, or
  revision semantics.

## Background

GH-142 requires high-fan-out Food, Recipe-publication, Daily Log, and USDA
builders to move into domain-specific test-support modules without changing
test semantics or production code.

P1 completed Food support. P2R1 completed Recipe support and reduced the
cross-test graph to 23 statements while deliberately leaving Daily Log and
USDA work for later slices.

A fresh non-mutating audit of archived main `05bca638e68a6b1bd4bc1b8d608efa7f84808a72` found:

- 145 backend `test_*.py` modules;
- exactly 23 remaining cross-test import statements;
- exactly five statements import `_post_log` and/or `_stored_log` from
  `tests.test_recipe_revision_logging`;
- `_post_log` is consumed by five test modules;
- `_stored_log` is consumed by two test modules;
- one additional statement imports `_create_serving_log` from
  `tests.test_recipe_revision_log_editing`;
- `_create_serving_log` is a generic Daily Log composite builder whose direct
  support dependencies are `_published`, `_post_log`, `_stored_log`, and
  `_default_serving`;

- collection remains 2262;
