# GH-200 — Prepare mobile evidence dependencies offline

## Goal

Let an attached mobile requirement execute against exact locked dependencies in the disposable evidence clone.

## Outcome

An explicit frozen opt-in preparation contract runs `npm ci` offline, without lifecycle scripts or network, before the sandboxed command. Preparation identity and logs are attached; a missing cache, invalid lock, or install failure is unavailable/failed evidence, never a pass.

## Non-goals

No implicit preparation, network/package download, main checkout mutation, change to ordinary qualification, or promotion of the attached lane.

## Background

Issue #198's frozen Jest command failed in the attached clone because it has no `node_modules`; its same locked command passed in a prepared local checkout. The disposable offline feasibility test passed against the controller's npm cache.

## Authority and precedence

Issue #200, exact external authorization, this capsule, and the trusted controller workflow are execution authority.

## Dependencies and prerequisites

Exact protected-main base above; planning P is a capsule-only child. The controller host supplies a local npm cache and supported macOS sandbox.

## Owned surface

Evidence parser/runner, its focused tests, the evidence contract document, and this capsule.

## Allowed changes

Add one opt-in mobile npm preparation value to a frozen requirement, validate it strictly, run lock-verified `npm ci --offline --ignore-scripts` in the disposable clone under deny-network/read-cache sandbox policy, and attach preparation metadata/logs. Keep no-preparation behavior unchanged.

## Forbidden changes

No mobile product code/dependency changes, shell-evaluated capsule command, package lifecycle scripts, cache writes, network grant, source checkout writes, or weakening of evidence failure gates.
