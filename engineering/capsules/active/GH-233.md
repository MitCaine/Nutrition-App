# GH-233 — Strengthen real RI consumer fixtures with independent expected results

## Goal

Make actual pinned-RI consumer tests fail when RI returns a self-consistent but incorrect declaration, range, kind, or incomplete change set.

## Outcome

Small fixtures independently specify complete expected declarations and file changes for the consumed Python, JavaScript, TypeScript, and TSX contracts. Explicit actual-runtime selection and native host proof remain visible.

## Non-goals

- No RI adapter changes or duplicated RI adapter suite.
- No runtime pin, application, controller, or review transport changes.

## Background

Issue #233 records that current real-package tests check hashes against RI-returned ranges and minimum declaration counts. These are useful integrity checks but do not independently prove correct complete results. RI navigation is source evidence only; this capsule owns the consumer tests.
