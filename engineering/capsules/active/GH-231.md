# GH-231 — Bind command evidence to the source copy actually tested

## Goal

Fix the gap where a local command can change the disposable clone, test changed tracked source, and still receive a passed exact-candidate record because only the original candidate is observed afterward.

## Outcome

Every passed local command record identifies the committed candidate source actually tested, while bounded generated test output remains possible.

- No product, dependency, RI package, or capsule authority change.
- No claim that local command success alone approves integration.
