# GH-142-P2R1 — Resume reusable Recipe construction and publication test builders

## Goal

Remove the remaining high-fan-out Recipe construction/publication test-module
authorities by moving stable Recipe builders into an explicit
`tests.support.recipes` module while leaving Daily Log behavior for a separate
GH-142-P3 slice.

## Outcome

When P2 is complete:

- `tests/support/recipes.py` is the explicit reusable Recipe-builder authority;
- `_per_100g_food` moves from `test_stage4_recipes.py` to public support
  function `per_100g_food`;
- `_create_recipe`, `_publish`, and `_history` move from
  `test_recipe_revision_publication.py` to public support functions
  `create_recipe`, `publish_recipe`, and `publication_history`;
- `_published` moves from `test_recipe_revision_logging.py` to public support
  function `published_recipe`;
- existing source tests may retain their historical private local names through
  import aliases, avoiding broad call-site churn;
- all cross-test imports of those five moved helpers are eliminated;
- `_post_log` and `_stored_log` intentionally remain in
  `test_recipe_revision_logging.py` for P3;
- the residual cross-test import graph falls from 39 statements to exactly 23;
- behavior and production code remain unchanged.

## Non-goals

- Moving `_post_log` or `_stored_log`.
- Moving `_create_serving_log`.
- Moving the capture/transition-specific `_published_recipe`.
- Moving `_projection_state`.
- Extracting general Daily Log support.
- Extracting USDA support.
- Refactoring Target, OCR, Phase 5, control-plane, or qualification helpers.
- Refactoring Recipe production behavior.
- Changing Recipe publication semantics.
- Changing helper payloads, endpoint expectations, or persistence semantics.
