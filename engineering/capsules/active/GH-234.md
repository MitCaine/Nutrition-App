# GH-234 — Reconcile RI source selection with independent reviewer read limits

## Goal

Allow bounded independent reviewer reads of every supported source file admitted by the 4 MB RI source selector, including long lines, without removing response or total-work limits.

## Outcome

Committed regular source blobs admitted by RI up to 4 MB can be read in bounded line ranges or exact byte chunks for long lines. Reviewer source access has explicit cumulative materialized-byte, per-response and call limits, and over-budget access fails visibly.

## Non-goals

- No unbounded full-file callback, broad source-selector expansion, RI runtime/pin change, or application change.
- No weakening of the full-diff or independent review obligation.

## Background

Issue #234 reproduces a 2.1 MB Python file admitted by RI but rejected by `read_blob` before the reviewer can request a short line range. RI is source evidence only; Nutrition owns reviewer access and qualification. The current 200 tool-call and 100 KB response limits remain.
