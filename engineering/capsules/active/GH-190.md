An explicitly attached capsule candidate carries authenticated qualification, command evidence and a fresh independent review receipt. A human-readable approval assertion alone cannot satisfy the attached lane. Existing non-attached compatibility remains until promotion.

## Return evidence

Exact candidate and authority, selected profiles, raw command results, runtime/model observations, fresh session/turn IDs, full AC matrix and findings, immutable public handoff, independent review and protected qualification. Missing observations remain unavailable, never success.

## Escalation conditions

Mismatched authority/source/runtime, unavailable required runtime capability, changed capsule contract, failed required proof, unknown review provenance, incomplete matrix, candidate mutation or exhausted correction stops eligibility. Material scope or trust-boundary change requires revised authority.

## Decisions and assumptions

Use a controller-owned, fresh reviewer process with explicit runtime binding. Prefer an environment-free reviewer session with bounded controller-served committed source, avoiding candidate tools or configuration. Default model policy is observed rather than invented; no silent requested-model fallback. Qualification commands remain controller/CI work, separate from reviewer judgment. State and private diagnostics stay outside candidate source. The existing trusted workflow bootstraps this tooling's acceptance; it must not approve itself with its new receipt generator.
