# GH-132-P4 — Clarify focused History reference crossings

## Goal

Make a small threshold crossing visually and textually legible in focused
History when a daily nutrient value is only marginally above the current
reference line.

## Outcome

Focused History retains its existing neutral reference line and bar geometry.

For every numeric day whose value is strictly greater than the current
reference:

- render a small neutral upward caret centered on that bar at the reference
  line;
- render the caret after the bars so a near-equal bar cannot obscure it;
- use only the existing `referenceLineColor`;
- use two rounded SVG line segments;
- make the caret exactly 12 pixels wide and 7 pixels high with a 2-pixel
  stroke;
- expose `above reference` in the date control accessibility label.

For a selected focused day that is strictly above the reference, append an
exact textual delta:

The suffix states the exact difference and its unit followed by `above reference`.

For example:

`2,301 mg · 1 mg above reference`

Equality is not a crossing. Values below the reference, explicit zero at or
below the reference, gaps, unavailable days, invalid references, and charts
without a reference do not receive a crossing caret or delta suffix.

The existing reference context remains responsible for semantic meaning such
as `Limit reference`, `Minimum reference`, `Neutral reference`, or
`Progress toward target`. `Above reference` is descriptive, not a
success/failure judgment.

## Non-goals

- No red, green, amber, warning, success, or failure coloring for crossings.
- No change to the reference-line color, width, position, or label.
- No change to bar height, chart scale, baseline, viewport, scrolling, slot
  width, touch target, or reference-value calculation.
- No visual exaggeration of a small numeric excess.
- No target-authority, target-direction, nutrition, projection, or persistence
  semantic change.
- No whole-screen History coloration.
- No theme or palette change.
- No P3R1 selected-date affordance change.
- No overview-chart reference or crossing behavior.
- No backend, API, runtime, package, navigation, or CI change.

## Background

P3R1 passed mandatory native light/dark physical qualification and is merged.

During physical review of focused Sodium History, a value materially above the
2,300 mg FDA Daily Value was easy to recognize because the bar visibly crossed
the line. The human owner identified the unresolved edge case: a value such as
2,301 mg would be numerically above a 2,300 mg reference but the geometric
difference would be substantially smaller than a reliable phone-scale visual
difference.

The approved solution is not to recolor the bar or distort its height. A small
neutral caret marks the actual reference crossing, while the selected focused
day reports the exact difference in text.

## Decisions and assumptions

- P4 marks every strict numeric crossing rather than using an arbitrary
  near-reference threshold. The cue therefore has one deterministic meaning.
- `numeric > reference` means `above reference`; it does not mean success,
  failure, healthy, unhealthy, compliant, or noncompliant.
- Existing reference context already states whether the line is a limit,
  minimum, neutral reference, or target-progress reference and remains
  unchanged.
- Caret color is exactly the existing `referenceLineColor`.
- Each caret is a 12-by-7-pixel upward chevron built from two 2-pixel rounded
  line segments centered on the bar/reference intersection.
- The caret renders after bars so a one-unit crossing remains visible.
- Exact selected-day subtraction uses canonical decimal strings and
  digit-by-digit decimal arithmetic rather than floating-point subtraction.
- The focused reference view model may retain the raw target amount string; the
  target model itself remains read-only.
- If a comparison input is not a canonical nonnegative decimal string, P4
  omits the delta rather than manufacturing one.
- Exact difference formatting preserves all meaningful fractional digits from
  the canonical subtraction while retaining normal thousands grouping.
- No material assumption remains unresolved at READY.
