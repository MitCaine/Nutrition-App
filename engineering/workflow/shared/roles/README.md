# Workflow roles

Each role has one entrypoint at the project’s selected RI revision. The controller
supplies the role document and complete assignment inputs through the supported
handoff; workers do not independently select newer RI instructions or repeat intake.

| Assigned role | Required role document |
| --- | --- |
| Controller | [Start an issue](../start-an-issue.md) |
| Capsule builder | [Capsule builder](capsule-builder.md) |
| Implementor | [Implementor](implementor.md) |
| Independent reviewer | [Independent reviewer](reviewer.md) |

The existing project map selects instructions and supplies commands, storage,
permissions and standards. If role documents are copied locally, bind their
locations and identities with that same selection. Installed skills resolve the
selected role through the handoff/map; a relative upstream link does not prove a
copied resource is available. Optional scope challenges, navigation evidence and
external watchers retain their targeted skill instructions, not another daily role.
