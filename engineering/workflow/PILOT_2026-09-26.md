## Decision, recovery and compatibility

**Owner decision, 2026-09-26:** retain the accepted trusted controller as the
default and keep the combined capsule/RI lane an opt-in trial. The owner also
chose to keep the exact #198 public evidence draft local; it has not been posted
to the issue. The decision follows the observed repeat attached-finalize
moved-refs stop, extra handoffs and absent active-time comparison. Passing
pilot tests does not establish a speed benefit or authorize a default cutover.
The [changelog](CHANGELOG.md) records this no-promotion outcome. Future
promotion needs new representative evidence and a fresh owner decision.
The #194 pre-pilot evidence-assembly/review-time baseline criterion remains
unmet: those active durations were not captured before the pilots and cannot
be reconstructed from wall-clock timestamps. This no-go closeout records that
limitation rather than marking a speed comparison as passed. Instrument and
compare those active durations in a later representative proving period before
proposing default promotion.

For a stopped task, re-read remote main, issue authorization, exact B/P/C, App checks,
review receipt, active capsule and HISTORY. Preserve failed candidates, raw evidence,
recovery R and the existing ruleset; never replay an old approval onto a new SHA.
Resume only the matching controller phase or create a new bounded authorization if
authority changed. For a partially integrated capsule, independently qualify the
HISTORY/deletion terminal T and verify protected main, recovery locator and issue
state before calling it complete. The current [closeout sequence](START_HERE.md)
remains the operator authority.

No live command or state store is retired by this pilot. `scripts/task` and its
unattached compatibility path remain necessary while the combined lane is opt-in.
`scripts/capsule` still supports explicit legacy capsule users. Exit criteria for
retiring any duplicate are an owner-approved default scope, representative stable
closeouts without moved-refs recovery, equal or better observed handoff cost,
inventory proving no live callers, and a reviewed migration/recovery plan. Historical
HISTORY commits and product control-plane artifacts are never deleted as cleanup.

Future dependency-update automation should inspect current declarations and resolved
locks, qualify compatible toolchains and fail closed on incompatible major/platform
changes. This pilot records observed versions solely as evidence, not as permanent pins.
