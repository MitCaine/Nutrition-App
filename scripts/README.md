# Scripts

| Script | Purpose |
| --- | --- |
| `run-backend-baseline.sh` | Ruff + ordinary pytest for the parked backend (no PostgreSQL needed). |
| `start-project.sh` / `stop-project.sh` | Start/stop the parked backend locally (needs PostgreSQL). |
| `start-backend.sh` | Backend process launcher used by `start-project.sh`. |
| `lib/` | Shell helpers for the above. |
